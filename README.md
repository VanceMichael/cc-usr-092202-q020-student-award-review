# 杰出学生评审证据室

管理杰出大专学生选举的提名证据、评委回避、多阶段评分、申诉冻结与结果发布。

## 业务事实

- 选举同时考察**学业成绩、领导才能、社会服务**，候选人经历分散在院校、社团与公益机构。
- **六类材料分别验真**：提名授权（提名机构）、成绩证明（院校注册组）、项目角色（社团）、服务时数（公益机构）、推荐意见（推荐人）、公开作品（公开链接存档）。
- 材料的**补交、更正、撤回均产生新版本**，`supersedes`/`successor` 双向成链；旧版本保留留痕，仅 `audit` 可见，不向评委或公众展示。
- 评委评分前须申报利益冲突；冲突名单、回避名单与各阶段面板一致，应回避的评委不出现在面板或评分记录中。
- **匿名初审、面谈、终审各自冻结评分标准**（`frozen_at` + 版本号），评分只能在冻结后提交且须引用当阶段冻结版本。
- 评分与同组中位数差距超过阈值（样例 20 分）只触发**复核**，复核结论绝不能是淘汰；样例中 cand-03 初审 62 分（差 23）触发复核后分数保留。
- 申诉受理即冻结：冻结时刻、证据版本（含旧版）、标准版本、有效评委与评分集合，事后可逐项核对。
- **获奖理由只能引用 confirmed 且验真 confirmed 的材料**；公开引用还须在授权 `published` 范围内。
- 未成年人须监护人联签，默认仅发布奖项与化名；敏感经历材料按授权范围展示，永不进入公开范围。
- 每个最终名次都有**重建包**：全部证据版本（含被取代/撤回的旧版）、三阶段冻结标准、各阶段有效评委、评分记录与申诉冻结编号。
- 未入选者资料按约定期限清理（样例为公布后 183 天，即 2026-12-20），删除可识别资料、仅留去标识统计。

| cand-03 丙 | 项目角色与服务时数包装被外部核验打回并更正；敏感经历脱敏；极端分差复核；未入选，到期清理 |

## 协作角色

- 候选人与提名人（未成年人含监护人联签）
- 资料核验人员（院校注册组、社团、公益机构、作品链接核验）
- 评委（按利益冲突回避分配）
- 申诉秘书处与结果发布人员

## 目录说明

- `contracts/domain.schema.json` 定义 v2 共享资料的字段、枚举与基本约束（11 个 `$defs`）。
- `fixtures/context.json` 提供不含真实个人信息的公开样例：3 名候选人、23 个材料版本、4 位评委、3 个阶段、27 条评分、1 条极端分差复核、1 宗申诉冻结、2 个名次与重建包、1 份到期清理安排。
- `src/records.py` 提供资料读取与领域不变量校验（版本链、回避一致、标准冻结、极端分差复核、申诉快照、发布引用、重建完整性、到期清理、未成年人/敏感信息授权）。
- `tests/test_records.py` 以"加载样例 + 变异样例"方式覆盖上述全部规则。
